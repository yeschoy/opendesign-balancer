开放导入接口（自动上号）

  1. POST ，请求头 Authorization: Bearer sk-odbimp-…（或 X-Import-Key）。导入密钥只能导入账号，不能调用模型；下游密钥也不能导入。
  2. 请求体：{"runtimeKey":"sk-amr-…","controlKey":"vela_ctrl_…","name":"账号名","group":"可选","note":"可选"}；批量用 {"accounts":[…]}，每次最多 200 个。不填 group 时用导入密钥的默认分组。
  3. 没有重复的账号立即入池并启用，备注自动写入导入时间与所用密钥；运行密钥、控制密钥或名称与现有账号相同时进入「账号」页的暂存区（HTTP 202），由管理员确认覆盖、作为新账号添加或丢弃。完全相同的账号重复提交返回 unchanged。
  4. 响应 {"added","staged","unchanged","failed","results":[{"index","status","accountId","stageId","conflicts","error"}]}；全部失败时 400，鉴权失败 401，同一 IP 鉴权连续失败 5 次后 60 秒内 429。
